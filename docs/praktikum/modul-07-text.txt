Static dan Dynamic Routing
7.1 Tujuan Praktikum
Mahasiswa diharapkan dapat:
1. Memahami konsep dasar routing dalam jaringan komputer serta peran
router sebagai perangkat pengarah lalu lintas data antar jaringan.
2. Memahami perbedaan antara static routing dan dynamic routing ,
serta menentukan kondisi penggunaan yang tepat untuk masing-masing
jenis.
3. Mengonﬁgurasi static routing pada router Cisco secara manual meng-
gunakan perintah ip route melalui CLI.
4. Mengonﬁgurasi dynamic routing menggunakan protokol Enhanced In-
terior Gateway Routing Protocol (EIGRP) pada topologi jaringan de-
ngan dua dan tiga router.
5. Memveriﬁkasi keberhasilan konﬁgurasi routing menggunakan perintah
show ip route , show ip interface brief ,d a nshow ip eigrp neighbor ,
serta melakukan uji konektivitas dengan ping.

7.5 Static Routing
Static routing adalah jenis routing yang mengharuskan administrator jaringan
untuk menambahkan setiap entri rute pada semua router secara manual.
Pendekatan ini masih layak diterapkan pada jaringan berskala kecil yang
tidak memerlukan banyak jaringan. Namun, pada jaringan yang lebih besar,
pengelolaan secara manual menjadi sangat tidak praktis karena setiap pe-
rubahan topologi mengharuskan pembaruan konﬁgurasi pada seluruh router
yang terlibat.
Kelebihan static routing antara lain: konﬁgurasi yang sederhana untuk
jaringan kecil, jalur routing yang dapat diprediksi, serta konsumsi sumber

7.8 Interior Gateway Protocols (IGPs)
IGP memiliki dua kategori utama berdasarkan algoritma yang digunakan,
yaitu Distance Vector (DV) dan Link State (LS) .
Protokol yang termasuk dalam kategori Distance Vector antara lain Rout-
ing Information Protocol (RIP), RIPv2, dan Interior Gateway Routing Pro-
tocol (IGRP). Sementara itu, kategori Link State mencakup protokol Open
Shortest Path First (OSPF) dan Intermediate System-to-Intermediate Sys-
tem (IS-IS).
Protokol Distance Vector bekerja dengan mencari rute terpendek berdasarkan
jumlah hop,y a i t uj u m l a hrouter yang dilalui sebuah paket dalam perjalanan-
nya menuju tujuan. Rute dengan jumlah hop paling sedikit akan dipilih
sebagai best route.
7.9 Exterior Gateway Protocols (EGPs)
EGP dirancang untuk pertukaran informasi routing antar autonomous sys-
tem yang berbeda. Salah satu protokol EGP yang paling banyak digunakan
adalah Border Gateway Protocol (BGP) ,y a n gm e n j a d ip r o t o k o ls t a n -
dar yang digunakan oleh Internet Service Provider (ISP) maupun perusahaan
berskala besar untuk mengelola pertukaran rute di tingkat internet global.
