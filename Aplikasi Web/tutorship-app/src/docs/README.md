# TutorCare — Platform Jasa Tutor (Milestone 1)

## Konsep & Deskripsi Produk
TutorCare adalah aplikasi web pencari guru privat yang sabar dan ramah untuk membantu siswa memahami pelajaran sekolah secara perlahan dan tanpa tekanan.

## Fitur Utama Milestone 1
- **Navigasi Multi-Halaman:** Beranda, Direktori Tutor, dan Tentang Kami.
- **Pencarian & Filter:** Filter berdasarkan mata pelajaran dan metode belajar (Online/Offline).
- **Pemesanan Sesi:** Modal formulir pemesanan dengan validasi sisi klien (client-side validation).
- **Aksesibilitas:** Skor Lighthouse Accessibility mencapai 90 dengan fitur pengubah ukuran teks (Bigger Text).

## Teknologi
- React, TypeScript, Tailwind CSS, Vite.

## Laporan Audit Aksesibilitas
- Skor Lighthouse Accessibility: **90**
- Perangkat: Desktop / Mobile
